Crie páginas simples para captar clientes locais

Este é o começo do MVP do seu app. A ideia aqui é permitir que negócios locais criem uma página com texto, botão de WhatsApp e formulário de contato.

Começar

1. Escolha um modelo

Selecione um template inicial para o seu tipo de negócio.

2. Preencha os dados

Informe nome do negócio, serviço, cidade e WhatsApp.

3. Gere sua página

Visualize o resultado e baixe a landing page pronta.
